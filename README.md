# ClipMaster---App
Windows automatic clipboard manager that saves everything you copy instantly. Features include smart categorization, advanced search, re-copy, easy delete, online/offline ads, Persian and English language support, dark modern UI. No installation needed, lightweight, works on Windows 10 and 11. Perfect for students, programmers, and professionals.
